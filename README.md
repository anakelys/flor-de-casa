# Flor de Casa — Landing Page

Projeto acadêmico fictício de uma landing page para uma pequena empresa de plantas e jardinagem.

## Arquivos
- `index.html`: estrutura e conteúdo da página.
- `style.css`: identidade visual, Flexbox e regras de responsividade.

## Como visualizar
Abra o arquivo `index.html` em um navegador. Não é necessário instalar ferramentas ou dependências.

## Recursos utilizados
- HTML5 semântico
- CSS3
- Flexbox para organização dos elementos
- Media queries para adaptação a tablets e celulares
- Formulário HTML demonstrativo

## Observação
O formulário é apenas visual e não envia mensagens. Para receber contatos de verdade, seria necessário conectá-lo a um serviço ou backend.
